## User
what is the procedure of repetition after fail

## Agent
Pulled Bachelor Informatik PO 2019 (§35, §40) directly via pdftotext since WebFetch's summarizer kept missing it. Key rules:
- §40(4): a failed Bachelorarbeit can be repeated exactly once; a different topic is issued.
- Topic-return option on the retake is allowed only if not already used on the first attempt; can't return twice.
- §37(3): failing below 4.0 triggers written notice with legal-remedy instructions on whether/when repeat is possible.
- §40(7): retake normally offered by end of that semester, latest start of next; same 9-week processing/registration rules as first attempt.
- §40(8): retake follows the same PO version as the original attempt.
- Failing the retake is final for the thesis (no third attempt).

## User
for example if i fail on 31.08 by not submitting?

## Agent
Missing the deadline (e.g. 31.08) without submitting = automatic "nicht ausreichend" (5.0) per §35(14), no partial-work grading. Triggers §37(3) written notice with legal-remedy info. Then §40(4) applies same as any fail: one retake, new topic, same 9-week rules; topic-return on retake only available if not already used on the first attempt. Retake isn't auto-scheduled — student must re-register via Prüfungsamt. Flagged that an extension (illness cert or justified-reason request, up to 50%/32 days, filed *before* the deadline) is the way to avoid triggering the fail/retake process if the deadline is at risk.

## User
when can i start next

## Agent
Per §40(7): retake normally offered by end of same semester as the fail, latest by start of next semester — no fixed date, since the 9-week clock starts from official topic-issuance, not the fail date. Practically: must actively re-register with Prüfungsamt, agree a new topic with a supervisor (same or different), and once officially logged, the 9-week window starts fresh. Real answer: can start as soon as new topic is agreed + officially recorded — no mandatory waiting period, but regulation expects it within ~one semester.

## User
so no waiting time needed?

## Agent
Correct per PO text: no mandatory cooling-off period. §40(4) just requires new topic; §40(7) is "soll" (should), not a hard deadline. Caveats: (1) "soll" cuts both ways — Prüfungsausschuss also isn't obligated to fast-track, and if topic-issuance runs on a semester cadence administratively, that could delay things without there being a legal minimum wait; (2) this is a reading of the PO text, not confirmed Informatik Prüfungsamt practice — recommended confirming with them or Ramesh directly.
