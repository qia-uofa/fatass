# Verbal Confidence in LLMs: Minimum & Recommended Reproduction Requirements

## 1. Minimum Requirement

**Datasets:**
- TriviaQA validation split, rc.nocontext config, deduplicated on normalized question text (~7,858 questions)
- Disjoint trial sets: 3,000 activation collection, 100 calibration (50 H/50 L), 200–500 per test experiment

**Models & Hardware:**
- Gemma 3 27B IT (primary model)
- GPT-4o-mini (grading TriviaQA answers)
- GPU: 1× H100 80GB (or 2× A100 40GB with device_map)

**Software Environment:**
- Python 3.10+, torch 2.3+ (CUDA), transformers 4.50+, scikit-learn 1.3+
- accelerate, datasets, numpy, scipy, pandas, matplotlib, openai, tqdm

**Configuration:**
- bfloat16 precision, eval mode, greedy decoding (temperature = 0)
- Categorical confidence prompt (Figure 8: ten unique class-initial tokens)
- Two-phase protocol: Phase 0 (answer generation + log-probs), Phase 1 (confidence elicitation with inserted answer)

**Hyperparameters & Metrics:**
- Layer sweep: 0, 10, 15, 20–35 (dense), 40, 50, 61
- Positions: PANL (post-answer newline), CC (confidence-colon), PANL+1 (control), AC (answer-colon)
- Metrics: accuracy, ECE (10 bins, no temp scaling), AUROC, logit difference, confidence change, first-token change rate
- Steering scales: α ∈ {2, 5}, normalized to 3% of residual-stream norm at each layer

**Interventions & Infrastructure:**
- Activation steering, patching (answer-token corruption + residual restoration), noising (mean ablation), swap (interchange intervention)
- Linear probing: Ridge R² (confidence prediction) and logistic AUROC (correctness prediction), 5-fold cross-validation
- Hooks applied after MLP block output; clean activations cached (float16, CPU)
- Verify class-initial token uniqueness and forward-pass–vs–generate equivalence before any intervention experiment

**Calibration Gate:**
- Baseline behavioral: accuracy 77.4%, ECE 0.12, AUROC 0.71 for Gemma on TriviaQA
- Do not proceed to intervention experiments until this replicates

## 2. Recommended Requirement

**Complete Dataset Coverage:**
- TriviaQA validation (primary, n≈7,858 + separate numeric prompt run n≈8,008 + minimal-numeric n≈2,000)
- BigMath (subset sampled to match 40.2% accuracy)
- MMLU (test split, sample to match 76.8% accuracy)
- TriviaQA answers graded and cached via GPT-4o-mini; verify zero hedging-language contamination

**Full Model & Architecture Coverage:**
- Gemma 3 27B IT, Qwen 2.5 7B Instruct (28 layers), Magistral Small 2506 (24B, 40 layers with CoT)
- Reasoning model requires full-trace storage + stratified activation set (retain all confidence ≤ 0.7, sample high-confidence remainder)

**Complete Prompts & Conditions:**
- Main: categorical (Figure 8), numeric 0–100 (Figure 15), minimal numeric 0–9 (Figure 16 for attention blocking)
- Magistral: Phase 1 CoT generation (max_tokens=1024), Phase 2 confidence with full reasoning trace + extracted answer
- Attention blocking requires `attn_implementation="eager"` (materializes full attention matrix; reserve ≥20 GB additional headroom)

**Complete Experimental Suite:**
- Experiments 0–8: behavioral baseline, steering (6 positions × 2 directions × 2 scales), patching, noising, swap, OOD control, AC nulls, attention blocking (12-layer windows, 5 pathways)
- Experiment 9 generalization: numeric, Qwen, BigMath, MMLU, Magistral (noising null expected for Magistral due to trace-distributed redundancy)
- Probing: both log-probability baselines (six individually + combined) and variance partitioning; intermediate tokens + reasoning-trace positions for Magistral

**Validation & Downstream Dependencies:**
- Donor–recipient length matching (10-quantile bins) for all swap experiments; report matching quality
- OOD dissociation test: PANL and PANL+1 within natural activation variability (cosine > 0.99, norm ratio 0.91–1.10) but opposite causal effects
- Phase-0 vs Phase-1 consistency (r ≈ 0.63)
- Attention blocking null on CC→Q+A confirms JIT ruled out; CC→PANL blocking (minimal prompt) shows ~21% disruption; PANL→answer disruption (~20%) precedes by 6–8 layers
